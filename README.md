# Max Heap Search Visualizer

互動式資料結構練習，使用純 HTML、CSS、JavaScript，無須安裝相依套件。

- 直接開啟 `index.html` 使用最大堆積與搜尋比較工具。
- 直接開啟 `hash.html` 使用雜湊表鏈結法視覺化工具。
- 直接開啟 `map.html` 查看 A、B、C、D、E、F 六個地點與九條道路，並選擇起點／終點播放 DFS、BFS 尋路動畫。
- 直接開啟 `hospital-rag.html` 使用院內規定 RAG 問答與餘弦相似度檢索示範。

## 功能

- 輸入整數數列，自動建立 Max Heap 並繪製堆積樹。
- 逐筆新增整數，或清空堆積。
- 使用 Max Heap 性質剪枝搜尋目標值，並在樹上標示檢查路徑。
- 將數列複製後以氣泡排序排序，再用二分搜尋尋找目標值。
- 顯示比較次數、交換次數、堆積大小、樹高、葉節點數與時間複雜度。

## 時間複雜度

| 方法 | 最佳 | 平均／最差 | 額外空間 |
| --- | --- | --- | --- |
| Max Heap 搜尋（利用堆積性質剪枝） | O(1) | 最差 O(n) | 最差 O(n) |
| 氣泡排序後二分搜尋 | 排序最佳 O(n)，整體 O(n) | 排序 O(n²)，二分搜尋 O(log n)，整體 O(n²) | O(n) |

Max Heap 只保證父節點不小於子節點，並非二元搜尋樹，因此一般搜尋最差仍須檢查 O(n) 個節點。氣泡排序法會先排序資料副本，不會改變畫面上的堆積。

## 雜湊表鏈結法練習

在 `hash.html` 中輸入以空格、逗號或換行分隔的 15 個整數，按下「建立雜湊表」即可查看 13 個桶位、碰撞鏈結與逐筆計算過程。頁面也提供範例載入及清除按鈕。

亦可執行 `python main10.py`，在命令列輸入 15 個整數。程式同樣使用 `數值 % 13` 計算索引，並以鏈結法將相同索引的數值串接顯示。

## 院規 RAG 問答示範

`hospital-rag.html` 將提供的 15 項院內規定整理成可查詢的問答頁面。資料處理與檢索流程如下：

1. **整理文件**：依原始編號將每一項規定拆成獨立片段，保留標題、時間、數量、禁止事項及例外條件；補充口語問法及檢索別名（例如「醫院幾點開」），回答仍引用原文。
2. **篩選清理**：統一全半形、英文字母大小寫及空白，清除無意義標點與常見語助詞；不移除否定詞、限制條件或數字。
3. **切詞向量化**：中文建立 2、3 字字元 n-gram（排除單字以減少雜訊），英文與數字以詞切分；將院規原文及每個口語別名分開建立 TF-IDF 向量。
4. **查詢與排序**：以相同方式向量化問題，分別比對院規原文與別名，取每項規定的最高餘弦相似度，排序並顯示前三筆來源。
5. **依據回答**：相似度達 0.25 才引用最高分院規原文並標示編號；最高分低於 0.25 時明確表示不清楚，提示補充關鍵詞，避免低相關度下猜測答案。

此示範完全在瀏覽器執行，不會將問題送到伺服器。TF-IDF 字元 n-gram 是可檢視的詞彙檢索方法，並非語意嵌入模型；餘弦相似度代表文字向量的相近程度，不代表醫療判斷或答案正確率。
